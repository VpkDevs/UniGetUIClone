## 2024-06-16 - [String Parsing Performance]
**Learning:** In C#, processing string inputs padded with multiple spaces via `Regex.Replace(line, @"\s+", " ").Split(' ')` or `Regex.Replace(line, " {2,}", " ").Split(' ')` allocates excessive memory and CPU cycles compared to standard string split mechanisms. Benchmarks show roughly 5x performance improvement by bypassing the regex and using `StringSplitOptions.RemoveEmptyEntries`. Note that when regex matches `\s+` (tabs and whitespace), it must be replaced with `line.Split((char[])null, StringSplitOptions.RemoveEmptyEntries)` instead of space split.
**Action:** Always prefer `StringSplitOptions.RemoveEmptyEntries` (with either `' '` or `(char[])null`) instead of preprocessing strings with `Regex.Replace` when parsing tabular space-padded command line outputs from package managers.
