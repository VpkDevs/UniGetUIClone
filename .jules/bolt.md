## 2024-05-14 - String splitting optimization
**Learning:** Found a common C# string tokenization anti-pattern throughout the PackageEngine managers. `Regex.Replace(line, " {2,}", " ").Split(' ')` was widely used to split string lines separated by multiple spaces. This executes a regular expression engine which involves more overhead and memory allocations compared to the native `.Split(' ', StringSplitOptions.RemoveEmptyEntries)` or `.Split((char[])null, StringSplitOptions.RemoveEmptyEntries)`.
**Action:** When tokenizing tabular CLI output separated by multiple spaces or whitespace in C#, prefer using `string.Split(' ', StringSplitOptions.RemoveEmptyEntries)` (for spaces) or `string.Split((char[])null, StringSplitOptions.RemoveEmptyEntries)` (for all whitespace) rather than pre-processing the string with `Regex.Replace(line, " {2,}", " ")` or `Regex.Replace(line, @"\s+", " ")` to significantly improve performance and avoid regular expression allocation overhead.
