## 2024-05-24 - Performance pattern in tabular CLI parsing
**Learning:** The project parses output from many CLI package managers. The output often involves columns separated by multiple spaces. I found that `Regex.Replace(line, @"\s+", " ").Split(' ')` or `Regex.Replace(line, " {2,}", " ").Split(' ')` are used repeatedly. According to memory, using `Regex.Replace` for tokenization is an anti-pattern when it can be replaced with `line.Split(' ', StringSplitOptions.RemoveEmptyEntries)` or `line.Split((char[])null, StringSplitOptions.RemoveEmptyEntries)` for zero-allocation/native string splitting. This change improves performance, especially during operations involving many lines of tabular CLI output.
**Action:** Replace `Regex.Replace` usages parsing whitespace in CLI tabular outputs with `Split` methods using `StringSplitOptions.RemoveEmptyEntries`. Note the subtle difference: `\s+` targets all whitespace (including tabs), meaning `(char[])null` should be used instead of just `' '` to match the exact `Regex.Replace` behavior if tabs might be present. `" {2,}"` targets spaces, meaning `' '` can be safely used.
