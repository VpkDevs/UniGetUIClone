## 2024-04-20 - Use Split() instead of Regex.Replace() for whitespace tokenization in Vcpkg.cs
**Learning:** In C#, replacing `Regex.Replace(line, @"\s+", " ").Split(' ')` with `line.Split(Array.Empty<char>(), StringSplitOptions.RemoveEmptyEntries)` works correctly to tokenize whitespace-separated tabular output. Note that `@"\s+"` matches any whitespace including tabs, whereas using `string.Split(' ')` directly wouldn't catch tabs, thus `Array.Empty<char>()` handles generic whitespace correctly without regex overhead and string allocation overhead.
**Action:** Replaced `Regex.Replace(line, @"\s+", " ").Split(' ')` with `line.Split(Array.Empty<char>(), StringSplitOptions.RemoveEmptyEntries)` in `Vcpkg.cs` and explicitly removed `System.Text.RegularExpressions` namespace to eliminate runtime memory allocation overhead. Always use this native Split approach instead of regex for simple space tokenizations.
