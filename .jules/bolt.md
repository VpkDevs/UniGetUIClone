## 2024-05-19 - Replace Regex.Replace with String.Split for tokenizing CLI output
**Learning:** In C#, processing text output from CLI tools that separate data fields with varying numbers of spaces using `Regex.Replace(line, " {2,}", " ")` or `Regex.Replace(line, @"\s+", " ")` before `String.Split(' ')` incurs significant overhead due to Regex engine allocation and string reallocation.
**Action:** Always prefer native string splitting with `StringSplitOptions.RemoveEmptyEntries`, e.g., `line.Split(' ', StringSplitOptions.RemoveEmptyEntries)` or `line.Split((char[])null, StringSplitOptions.RemoveEmptyEntries)`, to skip empty array fields caused by consecutive spaces directly, avoiding regex entirely. This is up to 5x faster in tight loops iterating over thousands of lines.
