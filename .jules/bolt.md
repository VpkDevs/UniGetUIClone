## 2024-05-24 - Performance pattern for string splitting
**Learning:** Found multiple instances of `Regex.Replace(line, " {2,}", " ").Split(' ')` or `Regex.Replace(line, @"\s+", " ").Split(' ')` used for tokenizing tabular CLI output. This pattern allocates strings unnecessarily and introduces regular expression overhead. The benchmark indicates that using `line.Split(' ', StringSplitOptions.RemoveEmptyEntries)` or `line.Split((char[])null, StringSplitOptions.RemoveEmptyEntries)` is nearly 10x faster and requires fewer allocations.
**Action:** Replace `Regex.Replace(line, " {2,}", " ").Split(' ')` and `Regex.Replace(line, @"\s+", " ").Split(' ')` with `line.Split(' ', StringSplitOptions.RemoveEmptyEntries)` throughout the package managers. This is a solid, targeted performance improvement.
