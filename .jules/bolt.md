## 2024-06-18 - Avoid String Concatenation and Splitting for Parser Performance
**Learning:** In C#, using string concatenation within loops (e.g., `versionItems[dotCount] += c;`) and using `string.Split()` intermediate arrays causes extremely slow parsing and creates massive garbage collection pressure, leading to roughly a ~4x slower operation. For hot paths like tokenizing simple numbers or version numbers, string manipulation allocations compound rapidly.
**Action:** Replace `string.Split` and `+=` inside loops with zero-allocation char-by-char traversal methods. For number parsing, use in-place integer arithmetic `(long)numbers[dotCount] * 10 + (c - '0')` directly while avoiding `int.TryParse`. This pattern must be actively considered for any tabular parsing or CLI data tokenizing.
