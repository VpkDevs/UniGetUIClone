## 2026-06-10 - Add ToolTips and AutomationProperties to WinUI Icon Buttons
**Learning:** In WinUI XAML code, simple icon buttons often lack built-in accessibility for screen readers and tooltips. Setting `AutomationProperties.HelpText` in XAML is a common anti-pattern for this project because it doesn't support localization natively in the XAML. Instead, both `AutomationProperties.SetName` and `ToolTipService.SetToolTip` should be used dynamically in the C# code-behind using `CoreTools.Translate()` to ensure full screen reader support and proper localization. This also requires explicitly adding `using Microsoft.UI.Xaml.Automation;`.
**Action:** When adding or updating icon-only buttons in WinUI components, always inject localized accessible names and tooltips in the C# code-behind (typically the constructor or initialization logic), ensuring the `Microsoft.UI.Xaml.Automation` namespace is imported.
