## 2024-03-24 - Accessibility for Reload and Search Buttons in Packages View
**Learning:** WinUI `AutomationProperties.HelpText` in XAML isn't sufficient or properly localized for primary labels on icon-only buttons. The correct pattern is to set `AutomationProperties.SetName` and `ToolTipService.SetToolTip` dynamically in the C# code-behind using `CoreTools.Translate()` to ensure screen readers and hover tooltips provide localized, accessible names.
**Action:** When improving WinUI XAML accessibility for icon-only buttons, avoid hardcoded XAML `HelpText`. Instead, programmatically set `SetName` and `SetToolTip` in the code-behind (`.xaml.cs`) utilizing the application's localization framework (`CoreTools.Translate`). Remember to include `using Microsoft.UI.Xaml.Automation;` if setting `SetName` in C#.
