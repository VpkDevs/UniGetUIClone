## 2024-11-20 - Accessible Names and Tooltips for Icon-Only Buttons in WinUI
**Learning:** In WinUI XAML, hardcoding `AutomationProperties.HelpText` (or setting properties statically in XAML) does not support localization cleanly. For icon-only buttons (like `ReloadButton` or `MegaFindButton`), the correct pattern is to set `AutomationProperties.SetName` and `ToolTipService.SetToolTip` programmatically in the C# code-behind using `CoreTools.Translate()` so that both screen readers and visual tooltips get the correct localized string.
**Action:** When adding or fixing accessibility for icon-only buttons, remove static `AutomationProperties.HelpText` or `ToolTipService.ToolTip` in XAML and instead initialize `AutomationProperties.SetName` and `ToolTipService.SetToolTip` in the code-behind using the localization service. Make sure `Microsoft.UI.Xaml.Automation` is imported.
