## 2024-05-14 - Dynamic Accessibility for Icon-only Buttons
**Learning:** In WinUI, icon-only buttons (e.g. `<FontIcon>` inside `<Button>`) do not inherit tooltips or accessible names by default. Although some `AutomationProperties.Name` are hardcoded in the XAML, for screen readers and localization (which require translations via `CoreTools.Translate()`), `AutomationProperties.SetName` and `ToolTipService.SetToolTip` must be set dynamically in the C# code-behind during initialization. This is currently missing for `MainToolbarButtonDropdown` and `ToggleFiltersButton` in `AbstractPackagesPage`.
**Action:** Always verify if an icon-only control has translated tooltips and ARIA-equivalent `AutomationProperties` in the code-behind. Hardcoded English strings in XAML like `AutomationProperties.Name="More actions"` are insufficient for localized UI and should be replaced dynamically.
