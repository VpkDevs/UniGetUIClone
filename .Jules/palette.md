## 2024-06-02 - Dynamic Accessibility and Localization for Icon-Only Buttons
**Learning:** In WinUI, hardcoding `AutomationProperties.HelpText` directly in the XAML for icon-only buttons limits their accessibility, particularly because it doesn't automatically support proper localization. Furthermore, `HelpText` without a localized `SetName` might lead to a degraded experience for screen reader users and those requiring tooltips in their native language.
**Action:** When adding accessibility or tooltip support to icon-only buttons, avoid hardcoded XAML properties like `AutomationProperties.HelpText`. Instead, dynamically set `AutomationProperties.SetName` and `ToolTipService.SetToolTip` in the C# code-behind using the project's localization tool (`CoreTools.Translate()`). Ensure this is done during control initialization (e.g., in the constructor) rather than within event handlers.
