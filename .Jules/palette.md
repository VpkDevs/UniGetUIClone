## 2024-05-12 - Localized Accessibility and Tooltips on WinUI Buttons
**Learning:** In WinUI applications using `AutomationProperties.HelpText` directly in XAML results in hardcoded strings that fail to localize or surface correctly to screen reader users in multi-language environments. Furthermore, icon-only buttons need explicit `AutomationProperties.SetName` (for screen readers) AND `ToolTipService.SetToolTip` (for visual mouse users), as they don't share identical text properties.
**Action:** When adding accessibility properties to UI elements (especially icon-only ones), set `AutomationProperties.SetName` and `ToolTipService.SetToolTip` dynamically in the `.xaml.cs` code-behind so they can utilize localization tools like `CoreTools.Translate()`. Ensure `Microsoft.UI.Xaml.Automation` is imported.
