## 2024-05-06 - WinUI 3 Icon-Only Buttons
**Learning:** Found that WinUI XAML `<Button>` elements using `<FontIcon>` or `<widgets:LocalIcon>` as content do not inherit tooltips or accessible names by default. In several data templates and list views, there are small icon-only buttons for actions like "Remove", "Open", and "Reset" that only have a glyph and lack an accessible label, making them inaccessible for screen readers and confusing for users who don't recognize the icon.
**Action:** Always add `AutomationProperties.Name` and `ToolTipService.ToolTip` mapped to a translated string (or plain text with translation markup, since UniGetUI uses `widgets:TranslatedTextBlock` normally, but XAML properties can't use translated components directly; however, we can add simple Tooltips for context).
