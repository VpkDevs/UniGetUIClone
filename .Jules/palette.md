## 2025-02-23 - Dynamic accessibility attributes in WinUI code-behind
**Learning:** In WinUI, visual state changes dynamically via event handlers (e.g. ExpandCollapseOpList changing its internal FontIcon Glyph upon click). Setting the ARIA `AutomationProperties.Name` and `ToolTipService.ToolTip` statically in XAML will miss these state changes. Additionally, the tooltips and names need localized strings using `CoreTools.Translate()`, which requires programmatically assigning them. The namespace `Microsoft.UI.Xaml.Automation` is necessary for `AutomationProperties.SetName`.
**Action:** When working on WinUI projects, check if dynamic buttons change states (like expand/collapse arrows). Make sure to dynamically update `AutomationProperties.SetName` and `ToolTipService.SetToolTip` within their `_Click` event handlers with the appropriately translated text, and ensure the initial state is translated in the constructor. Ensure `Microsoft.UI.Xaml.Automation` is included.
